# GuitarMatch

Каталог гитар, струн, усилителей и аксессуаров на React и Supabase. Можно искать товары по бренду и модели, применять фильтры категории, сортировать результаты и открывать карточки с характеристиками и фотографиями. Фильтры сохраняются в URL.

После регистрации можно открыть профиль и сохранить оборудование в избранное. Начальные данные включают 30 гитар, три комплекта струн и два усилителя. В публичном каталоге доступна Yamaha PAC112V с лицензированной фотографией. Позиции без проверенных фотографий остаются черновиками. Сохранение пресетов, аудио и AI-подбор пока не подключены.

## Локальный запуск

Нужны Node.js 24 и запущенный Docker.

```sh
npm ci
npx supabase start
```

Создайте `.env.local` по образцу `.env.example`. Укажите URL локального API и публичный ключ Supabase, которые показывает CLI.

```sh
npm run dev
```

Откройте адрес, который выведет Vite. Для production-сборки выполните `npm run build`.

Для входа и восстановления используйте порт 5173. Локальные письма Supabase доступны в Mailpit по адресу, который показывает `npx supabase status`. Ссылку из письма откройте в том же браузере, где заполнили форму. Для размещённого проекта добавьте адреса `/profile` и `/reset-password` в список разрешённых перенаправлений Supabase Auth.

## Структура

- `src/app/` — маршруты, общий макет и тема.
- `src/features/catalog/` — запросы каталога, фильтры, карточки и галерея.
- `src/features/account/` — авторизация, профиль и избранное.
- `src/shared/` — общие компоненты и клиент Supabase.
- `supabase/` — конфигурация, миграции и начальные данные.
